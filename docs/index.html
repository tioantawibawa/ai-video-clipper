Work with videos you own or have permission to repurpose. The pipeline prepares the edit; you check the context, captions, and final result.

01 — DISCOVER

Find a complete moment

Transcribe the source and use AI to suggest excerpts with a strong opening and a self-contained thought.

02 — SHAPE

Build the vertical edit

Trim pauses, reframe for 9:16, and add word-timed captions. Review framing and transcription before sharing.

03 — DECIDE

Review, then publish

Inspect the exported video and metadata. Publishing adapters require your own platform authorization and appropriate access.

This is the project's information website. It does not accept uploads, connect social accounts, or run the clipper in your browser.

  • The Python pipeline includes clipping, captions, metadata, and a review queue.
  • Social publishing adapters are implemented, but live integrations have not been verified with production credentials.
  • TikTok OAuth onboarding, token refresh, and a compliant creator export interface are not yet implemented. The project is not an approved TikTok integration.
