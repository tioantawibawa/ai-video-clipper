Privacy Policy

Effective date: September 28, 2026

This policy describes this static project website and the current self-hosted AI CLIPPER software. This website is not a hosted video-processing or social-login service.

Who maintains this project

AI CLIPPER is maintained by the GitHub account tioantawibawa. For project or privacy questions, open a general inquiry through the project issue tracker. Issues are public: do not include credentials, private videos, transcripts, or personal information.

When you visit this website

The website has no registration, upload form, social-login feature, advertising tracker, analytics script, or application cookies. Its images and styles are served from the same site. GitHub Pages hosts the website and may process technical request information such as IP addresses for operating and securing its service, under the GitHub Privacy Statement. Following external links takes you to services with their own policies.

When you run the software

The software runs on the computer or server where you install it. It downloads configured source media and stores generated clips, transcripts, metadata, queue records, and operational logs there. This website does not receive those files, and the maintainer does not automatically receive them.

  • Local Faster-Whisper transcription processes audio in your environment. Model files may be downloaded from external model repositories.
  • If you select API transcription, audio chunks are sent to OpenAI.
  • AI curation and metadata generation send transcript excerpts and related prompts to configured model providers. The default fallback sequence uses OpenRouter, then Google Gemini, then a paid model through OpenRouter. OpenRouter may route requests to its underlying providers.
  • If you configure and authorize publishing, videos and metadata are sent to the selected social platform. Account tokens are used to authenticate those requests.
  • If you configure a proxy or public media host, those services handle the corresponding network requests or files. Instagram publishing requires an accessible media URL.

Only process content you are authorized to share with the providers you select. Their processing, retention, training, and cross-border handling practices are governed by their own policies and your account settings.

Storage and retention

API keys and account tokens are supplied through your environment or local configuration. Protect those files and do not commit them to Git. Staged clips and manifests remain in your deployment until you remove them; queue records also persist. Application logs are configured for 14-day retention. Temporary files are normally removed after processing, but a forced shutdown can leave temporary files behind. Your backups and hosting configuration may retain additional copies.

Your controls

You can stop the worker, remove monitored sources, delete locally stored media and data, change providers, or revoke platform authorization through the relevant account settings. The current project does not provide a hosted account or an online data-deletion endpoint. Requests concerning data held by GitHub, an AI provider, or a social platform should also be directed to that provider.

Changes

This policy will be updated if the project's actual data handling changes. A future hosted service or social-login interface would require updated disclosures before collecting information.
