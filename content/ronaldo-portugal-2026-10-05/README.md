# Ronaldo / Portugal original explainer

Facts checked 5 October 2026 against EFE and RTP; source URLs are embedded in each plan.
Do not convert an unconfirmed return into a retirement or a guaranteed starting place.
The scripts distinguish reporting, opinion and hypothetical tactical illustrations.
All pitch graphics are generated by us. No real match footage, player tracking,
gameplay results, impersonation or cloned voices are used.

The English narration uses a generic synthetic voice. There is no promise of views,
CTR, retention or YouTube recommendation placement.

## Laptop production

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-content.txt
$env:PYTHONPATH='src'
.venv\Scripts\python.exe content/ronaldo-portugal-2026-10-05/build_plans.py
.venv\Scripts\python.exe -m clipper.explainer content/ronaldo-portugal-2026-10-05/main.json --output data/original-ronaldo/main
.venv\Scripts\python.exe -m clipper.explainer content/ronaldo-portugal-2026-10-05/short-1.json --output data/original-ronaldo/short-1
```

Repeat for short-2 and short-3. Audio and word timestamps are cached by narration
and voice; temporary frame files and intermediate videos are cleaned after rendering.
Each Short is rejected if the actual audio is longer than 45 seconds.

## Public release

Transfer completed MP4/manifest files into a dedicated VPS production folder,
**not** the automatic outbox, then use `scripts/schedule_original.py` on the VPS.
It reserves the existing account quota before uploading, uploads privately with
YouTube `publishAt`, records `scheduled`, and never retries an uncertain outcome.
The normal daemon verifies public visibility once the release time has arrived.
An existing queue record is returned without another upload.

Upload the main episode first, then Shorts in order. One public video per account
day remains in effect. Once the main episode becomes Public, add it to each Short
using Studio's Related Video control. This control is not implemented by the public
YouTube Data API adapter. A URL in the description is not a substitute.
